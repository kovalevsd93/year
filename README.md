# Годовая подписка — лендинг

Одностраничник акции «Годовая подписка к новому учебному году» Академии
здорового мышления Павла Федоренко. Замена странице
[fedorenko.academy/8marta](https://fedorenko.academy/8marta): блоки, структура
и тексты сохранены, первый экран и оформление переделаны.

Собирается статически: Python без зависимостей превращает исходники в один
самодостаточный `index.html` — шрифты и локальные картинки вшиты в файл,
поэтому его достаточно просто положить на хостинг.

## Сборка

```bash
python3 build.py        # -> index.html   (продакшн)
python3 make_preview.py # -> preview.html (всё вшито, включая отзывы)
```

Зависимостей нет. Из внешних утилит нужен только `sips` — он есть в macOS
из коробки и используется для сжатия картинок.

Разница между файлами: в `index.html` скриншоты отзывов тянутся с Tilda CDN,
в `preview.html` вшиты в документ — он тяжёлый и нужен только для показа.

## Что где лежит

| Файл | Отвечает за |
|---|---|
| `data.py` | **все тексты, цены, даты и палитра** — обычно правки нужны только здесь |
| `build.py` | разметка: собирает секции и пишет `index.html` |
| `css.py` | стили одной строкой-константой |
| `icons.py` | иконки в SVG |
| `figure.py` | манекен в блоке «четыре уровня работы» и подсветка зон |
| `inline.py` | сжатие и вшивание картинок в документ |
| `png.py` | свой минимальный чтец и писатель PNG (Pillow в системе нет) |
| `cutout.py` | отделение фона от снимка: `python3 cutout.py вход.png выход.png` |
| `privacy.txt` | текст политики конфиденциальности |
| `assets/` | картинки, которые вшиваются в страницу |
| `бонусы/` | скриншоты для блока бонусов |

## Частые правки

Всё перечисленное — в `data.py`:

- **Дата окончания акции** — `DEADLINE_TEXT` и `DEADLINE_ISO` (по ним же
  считается таймер в шапке и стаж Павла).
- **Цена, старая цена, скидка** — в `build.py`, функция `price()`.
- **Состав подписки** — `INCLUDED` и `INCLUDED_BONUSES`.
- **Программы** — `PROGRAMS`, метаданные карточек — `COURSE_META`.
- **Расстройства** — `DISORDERS`, порядок задаёт порядок карточек.
- **Инструменты платформы** — `TOOLS`.
- **Ссылка на оригинал отзыва** — `REVIEW_SOURCE`.
- **Палитра** — `SPECTRUM` (спектр логотипа) и `LEVEL_COLORS`.

## Картинки

Скриншоты бонусов подхватываются из папок автоматически, в порядке имён
файлов:

```
бонусы/ассистент/   отзывы об ИИ-ассистенте
бонусы/платформа/   скриншоты платформы (сейчас в вёрстке не показываются)
```

Формат и размер значения не имеют — при сборке всё ужимается и вшивается.

## Что осталось подключить

- Кнопки «Оформить подписку» ведут на `#order`; нужна форма оплаты.
- Кнопка «Получить консультацию» ведёт на `#consult-form`; нужна форма заявки.
- «Оригинал отзыва» у всех карточек ведёт на один адрес: `REVIEW_SOURCE`.
  Если есть ссылки на конкретные посты — их нужно проставить по отзывам.
- Скидка на странице указана **79%**: это честная разница между 110 000 ₽
  и 22 800 ₽. Если нужны заявленные 85%, старая цена должна быть 152 000 ₽.
