Оригиналы картинок, из которых собраны файлы в `assets/`.

- `павел.png` → `assets/pavel-course.jpg` (портрет на карточке флагмана;
  подложен цвет плашки и пересохранён в JPEG, иначе PNG с прозрачностью
  весил бы больше всей страницы)
- `maneken.png` → `assets/mannequin.png` (манекен в блоке «четыре уровня»)
- `nokub.png`, `kub.png`, `8f2hz…png` — другие варианты съёмки манекена,
  в вёрстке не используются

Пересобрать вырезку: `python3 cutout.py вход.png выход.png`
